# OutBack MATE3s

Home Assistant custom integration for direct OutBack MATE3s Modbus TCP telemetry and selected controls.

Current version: **1.2.4**

Realtime telemetry refreshes every 10 seconds. Writable/configuration values refresh every 5 minutes and can be refreshed manually using **Refresh Control Data**.

See the repository README for supported sensors, controls, installation and safety notes.

Temperature entities use degrees Fahrenheit (°F) as their native/default unit.
